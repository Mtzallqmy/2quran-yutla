# تقييم مصادر المحتوى الصوتي

## ما تم التحقق منه مبدئيًا

| المصدر | النتيجة | قرار الدمج |
|---|---|---|
| MP3Quran API | صفحة واجهة رسمية منشورة وتذكر توفير قوائم اللغات والسور والروايات والقراء. | مرشح لكتالوج القراء والسور، ويستلزم فحص الاستجابة الحية وتوثيق شروط الاستخدام قبل العرض الإنتاجي. |
| تطبيق إذاعة القرآن من القاهرة | صفحة Google Play تصفه بوضوح بوصفه المنصة الرسمية للبث المتواصل من المصادر الأصلية، ومن تطوير MCIT Egypt. | مصدر مرجعي موثوق لفهم تجربة الإذاعة، لكن لا يُستخرج منه رابط بث أو يُعاد توزيعه دون رابط رسمي مصرح. |
| إذاعة البحرين | صفحة الجهة الرسمية طلبت تحققًا بشريًا في بيئة الفحص. | لا تعتمد في كتالوج التطبيق إلى حين توفر رابط بث رسمي قابل للتحقق. |
| EveryAyah | موقع علني يعرّف أرشيف ملفات تلاوة بحسب القارئ والآية. | مصدر محتمل للتلاوة بحسب الآية، ويستلزم مراجعة ترخيص المحتوى وملاءمته للتنزيل قبل الاستخدام. |
| Quran Foundation | بوابة المطورين توثق واجهات محتوى للسور والتلاوات والصوت، لكنها تتطلب إنشاء تطبيق وبيانات اعتماد خادمية لبيئة الإنتاج. | مصدر مفضل للتوسعة الإنتاجية عند توفير بيانات الاعتماد، ولا تُوضع المفاتيح داخل تطبيق الهاتف. |
| AlQuran Cloud | وثائق REST علنية وفهرس فعلي للسور أعاد استجابة ناجحة تشمل أرقام السور وأسماءها وعدد آياتها. | يعتمد لفهرسة السور الأساسية في الإصدار الحالي، مع بقاء التحقق المستقل من مصدر الصوت وتنزيله مطلوبًا لكل قارئ. |

## قواعد الاعتماد

لا يُعرض أي مصدر في واجهة الإنتاج إلا إذا كان رابط التشغيل HTTPS وقابلًا للاختبار ومرتبطًا بجهة واضحة، مع توثيق مزود المحتوى وحالة الفحص ووقت التحقق. لا تُستخدم نتائج أدلة خارجية أو روابط مجهولة المصدر كبث رسمي.
