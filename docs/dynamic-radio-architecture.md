# بنية المحتوى الديناميكي وإذاعة «قرآن يتلى»

## المبدأ

تكون D1 المرجع الوحيد للبيانات وR2 مخزنًا للنسخ الصوتية والصور. لا يحتوي تطبيق الهاتف على قائمة قراء أو روابط ملفات ثابتة؛ يعرض فقط السجلات المنشورة والفعالة التي تعيدها واجهة Worker العامة.

## طبقات المحتوى

| الطبقة | المسؤولية | قاعدة الأمان |
|---|---|---|
| D1 | القراء والمصاحف والأصول وإصداراتها والمحطات وقوائم البث | حالة النشر والترتيب والإصدار هي مرجع الحقيقة |
| R2 | MP3 والصور والنسخ غير القابلة للتغيير | مفتاح جديد لكل إصدار مع SHA-256 محفوظ |
| Worker | القراءة العامة، البث الجزئي، ETag، وعمليات الإدارة المحمية | لا يصل تطبيق الهاتف إلى رمز الإدارة أو قاعدة البيانات |
| تطبيق Expo | عرض نسخة محلية ثم التحقق الشرطي وتشغيل الأصل الحالي للمحطة | لا يعرض المحتوى المخفي أو غير المفعّل |

## واجهات القراءة والنشر

| الواجهة | الاستخدام | التخزين المؤقت أو الحماية |
|---|---|---|
| `GET /v1/content/manifest` | بصمة موحدة لعدادات وإصدار الفهرس | ETag و`304 Not Modified` قبل جلب الكتالوج كاملًا |
| `GET /v1/quran/surahs` و`GET /v1/media` | السور والأصول المنشورة فقط | ETag وLast-Modified وترقيم صفحات بـ `cursor` و`limit` |
| `GET /v1/radio/stations/:id/now` | المقطع الحالي والتالي وموضع البدء المحسوب | تحديث كل 15 ثانية وعند نهاية المقطع |
| `GET /v1/images/reciters/:id` | صورة القارئ المنشورة من R2 | نسخة غير قابلة للتغيير، ولا يظهر المرجع غير المنشور |
| `/v1/admin/*` | إنشاء القارئ أو المحطة، ترتيب القائمة، النشر والإخفاء والرفع | رمز الإدارة على الخادم فقط؛ الطلب غير المصرح يعيد 401 |

## الصور والإسناد

تُنشأ بيانات القارئ منفصلة عن الملف الصوتي، وتحفظ كل صورة في `reciter_image_versions` بمفتاح R2 جديد وبصمة SHA-256 ورابط مصدر HTTPS ونص إسناد اختياري. لا تستبدل الصورة القديمة داخل R2، بل يُحدَّث مرجع القارئ إلى الإصدار الجديد، ما يسمح بالتدقيق والاسترجاع دون كسر التطبيق.

## الإذاعة الخاصة في الإصدار الأول

المحطة ليست رابطًا خارجيًا ولا تدفقًا مجهول المصدر. تحفظ المحطة قائمة أصول مرخصة مرتبة، ووقت مرساة ثابتًا. تحسب واجهة «يُبث الآن» المقطع الحالي وموضعه من الزمن الإجمالي للدورة، ثم يشغّل التطبيق الملف مباشرة من R2 عند ذلك الموضع. بذلك يرى جميع المستمعين البرنامج نفسه دون خادم ترميز متصل دائمًا.

## التوسع لاحقًا

يضاف HLS المتصل فقط عندما تتطلب الخدمة انتقالات صوتية أو إدخالات حية أو تطابقًا صارمًا بين المستمعين. عندها تكون قائمة R2 الحالية هي مصدر الإدخال المرخص، ويضاف خادم ترميز ومراقبة تشغيلية منفصلان؛ لا تُستبدل طبقة الحقوق أو D1.
