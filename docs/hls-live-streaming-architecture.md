# دعم HLS للبث الحي في «قرآن يتلى»

## النتيجة المعتمدة

يعرض التطبيق القنوات الحية من فهرس D1 فقط. تسجل كل قناة رابط قائمة HLS (`.m3u8`) ومالك مصدر البث وحالة النشر والإسناد. لا تُحفظ مفاتيح البث أو بيانات إدخال RTMPS/SRT داخل التطبيق أو Worker العام.

## مسار البث الحي

1. ينشئ المالك مدخل بث مباشر لدى Cloudflare Stream ويحتفظ بمفتاح RTMPS أو SRT في بيئة البث فقط.
2. يرسل برنامج البث من مصدر معتمد إلى المدخل، وتنتج خدمة البث قائمة HLS قابلة للتشغيل.
3. يسجل المالك في لوحة الإدارة رابط قائمة HLS، مصدر الحقوق، والإسناد وحالة النشر.
4. يعيد Worker القنوات المنشورة فقط للتطبيق، ويتحقق مشغل الصوت من علامة `#EXTM3U` وتوفر المصدر عند الفحص الإداري.

> وثائق Cloudflare Stream تؤكد أن Live Input يُنشأ من لوحة التحكم أو API، وأن الإرسال يتم عبر RTMPS أو SRT، بينما يستطيع أي مشغل متوافق مع HLS أو DASH تشغيل المخرج. لن نفعّل قناة مباشرة قبل إدخال مصدرها وترخيصها في سجل الحقوق.

## حدود الإصدار

يدعم هذا الإصدار فهرسة وتشغيل HLS الحي ومراقبة توفره من التطبيق. أما الترميز المستمر، والانتقالات بين ملفات R2، أو إدخال المذيع الحي فتعمل في خدمة بث مستقلة؛ لا يمكن لـ R2 أو Worker وحدهما تحويل MP3 إلى HLS حي متصل.

## قائمة تشغيل Cloudflare Stream للمالك

> **لا تضع مفتاح RTMPS أو SRT ولا رمز Cloudflare API داخل التطبيق أو في سجل D1.** يحتفظ بهما مشغّل البث في OBS أو في بيئة ترميز مستقلة فقط.

1. من حساب Cloudflare، اشترك في **Stream** ثم أنشئ **Live Input** من صفحة **Live inputs**؛ أو أنشئه عبر واجهة `POST /accounts/{account_id}/stream/live_inputs` عند الحاجة إلى أتمتة خاضعة للضبط.[1]
2. اضبط `recording.mode` على `automatic` إن كانت إعادة المشاهدة وخرج HLS/DASH مطلوبة، لأن وضع `off` لا يجعل الإدخال متاحًا للمشاهدة أو التسجيل. لا تفعّل `requireSignedURLs` إلا إذا كان التطبيق يملك خدمة آمنة لتوليد التواقيع وقت المشاهدة.[1]
3. انسخ عنوان RTMPS ومفتاح البث إلى OBS أو خادم الترميز فقط. اضبط العميل على إعادة الاتصال، وبترميز H.264/AAC وGOP مغلق مدته بين ثانيتين وثماني ثوانٍ؛ هذه متطلبات وتوصيات Cloudflare للبث المستقر.[1]
4. ابدأ البث وتحقق من المعاينة في لوحة Stream. استخرج **رابط ملف HLS العام الفعلي** من واجهة تشغيل Cloudflare أو من بيانات المشاهدة في الـ API، ثم أضفه إلى لوحة **قنوات HLS الحية** بصيغة HTTPS تنتهي بـ `.m3u8`.
5. اختر فقط مصدر حقوق مفهرسًا في D1 بحالة `stream_link_only` أو `attribution_required` أو `r2_redistribution_allowed` مع `streaming_allowed = 1`. لا يعني امتلاك مدخل Stream امتلاك حق إذاعة التلاوة أو إعادة بثها.
6. احفظ القناة أولًا كمسودة، شغّل **فحص توفر قناة HLS**، وراجِع حالة الفحص والإسناد. انشرها فقط بعد نجاح الاختبار وبعد أن يثبت السجل القانوني حق البث المباشر.
7. عند الاشتباه بانكشاف مفتاح البث، دوّر مفاتيح Live Input فورًا؛ تُبطل Cloudflare المفاتيح القديمة وتقطع الاتصالات التي تستخدمها.[1]

## نموذج التشغيل الصوتي

هذا التطبيق يستخدم `expo-audio` لتشغيل رابط HLS الموجود في الفهرس دون تنزيله أو إدخاله إلى التنزيلات المحلية. القنوات الحية لا تحمل بصمة ملف أو حجمًا متوقعًا، لأن قائمة HLS والمقاطع تتغير باستمرار. عند فشلها، تبقى الإذاعة المجدولة من أصول R2 المتاحة كمسار استماع مستقل وآمن.
