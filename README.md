# قرآن يتلى

تطبيق عربي حديث للاستماع إلى إذاعات القرآن والتلاوات المختارة وقصص الصحابة. صُمم التطبيق بتجربة RTL أولًا، وهوية بصرية هادئة، وتشغيل صوتي محلي، ومفضلة، وقوائم تشغيل محفوظة على الجهاز.

> **من تطوير معتز العلقمي**

## المزايا

| المجال | ما يتوفر في النسخة الحالية |
|---|---|
| الاستماع | محطات مباشرة وتلاوات مختارة مع مشغل كامل ومشغل مصغر ثابت |
| المحتوى | بحث وتصنيفات للمحطات والقصص والقراء وصفحة تفاصيل لكل عنصر |
| المكتبة | مفضلة دائمة وقوائم تشغيل محلية قابلة للإنشاء والإضافة |
| التجربة | RTL، سمة فاتحة/داكنة، ردود لمس خفيفة، مؤقت نوم، وسرعة تشغيل في الواجهة |
| التقنية | Expo SDK 54، React Native، Expo Router، TypeScript، AsyncStorage، Expo Audio |

## التشغيل المحلي

```bash
pnpm install
pnpm dev
```

لتشغيل فحوصات الجودة:

```bash
pnpm check
pnpm test
pnpm lint
```

## البنية

```text
app/                 مسارات Expo Router والشاشات
components/          بطاقات المحتوى والمشغل المصغر والعناصر المشتركة
lib/quran-data.ts    كتالوج محلي صغير قابل للاستبدال بمصدر بيانات موثوق
lib/player-context   حالة المشغل والمفضلة وقوائم التشغيل
lib/quran-theme      الألوان والسمة الدائمة
assets/images/       أيقونة «قرآن يتلى» وملفات splash وAndroid
```

## ملاحظات المحتوى

النسخة الحالية تتضمن كتالوج بداية محليًا لتطوير الواجهة والتدفقات. روابط الاستماع تحتاج إلى مراجعة دورية من صاحب المشروع قبل أي إصدار إنتاجي، كما يُنصح بتوفير مصدر بيانات versioned للتحكم بالمحطات والقراء دون الحاجة إلى نشر إصدار جديد من التطبيق.

## خارطة توسع مقترحة

يمكن توسعة التطبيق لاحقًا بإضافة تنزيلات دون اتصال، والتحقق من سلامة مصادر البث مع بدائل تلقائية، ومزامنة اختيارية للمكتبة بين الأجهزة، وتنبيهات محلية، وتحليلات تحترم الخصوصية.
